The legendary Pokémon binder page

A legendary trio is three Pokémon, and a nine-pocket page has three rows, so three trios fill the page exactly. Give each trio its own row and the page holds the birds of Kanto, the beasts of Johto and the giants of Hoenn at once: the Pokémon each journey builds up to, together on one page.

Twelve trios fill four pages. Alola's four Tapus and Paldea's four Treasures of Ruin come in fours, not threes: give each group the four corners of a page.

Two layouts, compared

1. Three trios, one per row. The page pictured above. Each row is a different trio, read left to right. Kanto, Johto and Hoenn on one page is the classic choice; any three rows of the table work the same way.

2. One trio, three ways. Each column is one Pokémon and each row is a different set, so you see the same trio change from one era to the next. The legendary birds suit this best, because so many sets have all three.

Matching borders

Cards from the same years share one frame, so the page looks made to go together. The page at the top of this guide uses three sets from the Diamond & Pearl years: Majestic Dawn for the birds, Secret Wonders for the beasts and Legends Awakened for Kyogre, Groudon and Rayquaza. All nine have the same yellow border. If you would rather mix eras, keep each row to one set so every trio still matches itself. Next to a legendary page, a starter page makes a binder that opens with the first Pokémon of each journey and builds to the last.

Try it before you sleeve

Moving nine cards around a real page is slow, and every move risks a scuff. Try the order on screen first, as many times as you like.

  1. Open the free page builder. No account needed.
  2. Type a name, such as Articuno. The builder lists its cards with the set each one comes from. Add the set, such as Articuno Majestic Dawn, to see only that set's cards.
  3. Tap one card for each Pokémon, in the order you want them. Pockets fill in the order you tap. For the page above: Articuno, Zapdos, Moltres, Raikou, Entei, Suicune, Kyogre, Groudon, Rayquaza.
  4. Tap See page. Tap a card to take it out, then add another, until the page looks right.
  5. Keep the page with a free account, then sleeve the real cards in the same order.

Questions

What are the legendary trios?

Groups of three legendary Pokémon that belong together, such as the legendary birds Articuno, Zapdos and Moltres from Kanto and the legendary beasts Raikou, Entei and Suicune from Johto. This guide lists twelve of them, from Kanto to Galar.

How many binder pages do the legendary trios need?

One row per trio and three trios per page, so the twelve trios in this guide fill four nine-pocket pages.

Which sets have all three legendary birds?

Fossil from 1999, Legendary Collection, Majestic Dawn and Legendary Treasures all have Articuno, Zapdos and Moltres. The page pictured in this guide uses the Majestic Dawn birds.

Should a trio go in a row or a column?

A row, read left to right, if each row is a different trio. Columns if you want one trio three times, with each Pokémon down its own column and each row a different set.

Is the page builder free?

Yes. Planning a page needs no account. Keeping it makes a free account, which never asks for payment details.
